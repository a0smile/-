# 🦷 موقع مجمع عناية الابتسامة الطبي

موقع إلكتروني لطب وجراحة الأسنان — **كل التعديلات من ملف واحد فقط، بدون لمس أي كود**.

---

## 📁 الملفات

| الملف | هل تعدّله؟ |
|------|-----------|
| `content.json` | ✅ **نعم — هذا ملفك الوحيد للتعديل** |
| `index.html` | ❌ لا تلمسه |
| `style.css` | ❌ لا تلمسه |
| `main.js` | ❌ لا تلمسه |

---

## ✏️ كيف تعدّل موقعك (بدون برمجة)

1. افتح مستودعك في GitHub
2. اضغط على ملف `content.json`
3. اضغط رمز القلم ✏️ (Edit)
4. غيّر النصوص **بين علامتي التنصيص `" "` فقط**
5. اضغط **Commit changes**
6. بعد دقيقة تقريباً يتحدّث موقعك تلقائياً ✅

### ⚠️ قواعد مهمة جداً

- لا تحذف علامات التنصيص `" "`
- لا تحذف الفواصل `,` أو الأقواس `{ }` `[ ]`
- غيّر **النص الذي بين التنصيص فقط**، ولا تغيّر الكلمات الإنجليزية على اليسار

---

## 📞 مثال: تغيير رقم الجوال والواتساب

في أعلى `content.json`:

```json
"phone": "+966500000000",
"whatsapp": "966500000000",
```

ضع رقمك الحقيقي. رقم الواتساب يكون **بدون + وبدون صفر البداية** — مثال: الرقم `0501234567` يصبح `966501234567`

---

## 🔥 مثال: إضافة عرض جديد

انسخ هذا المقطع داخل `"items"` في قسم العروض:

```json
{ "icon": "🦷", "title": "اسم العرض", "oldPrice": "500", "price": "350 ريال", "note": "جديد" }
```

ولا تنسَ الفاصلة `,` بين كل عرض والذي بعده.

### إخفاء قسم العروض بالكامل:

```json
"enabled": true
```

غيّرها إلى:

```json
"enabled": false
```

## ➕ مثال: إضافة خدمة جديدة

داخل `"services"` أضف:

```json
{ "icon": "😄", "title": "اسم الخدمة", "description": "وصف مختصر للخدمة" }
```

يمكنك نسخ أي إيموجي من: [emojipedia.org](https://emojipedia.org)

## 🌐 النشر المجاني (GitHub Pages)

1. اجعل المستودع **Public** (من Settings → General → Danger Zone → Change visibility)
2. من **Settings → Pages**
3. في **Source** اختر **Deploy from a branch**
4. اختر فرع **main** واضغط **Save**
5. بعد دقيقتين سيكون موقعك على:
   `https://اسم-المستخدم.github.io/a0smile/`

### ربط نطاق خاص لاحقاً (مثل enaya-smile.com)

عند شرائك نطاقاً: من **Settings → Pages → Custom domain** اكتب النطاق، ثم أضف سجلات DNS عند مزود النطاق (GitHub يعطيك التعليمات خطوة بخطوة).
